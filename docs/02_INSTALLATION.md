# 🚀 Инсталация и Конфигурация

Този раздел съдържа подробни инструкции за инсталиране, настройка на зависимосттие и конфигурация на **TMX Processor** за различни среди (десктоп, сървър, CI/CD).

---

## 📋 Изисквания

- **Python**: Версия `3.9` или по-нова (3.9, 3.10, 3.11, 3.12).
- **Операционна система**: Linux, macOS, Windows.
- **RAM памет**:
  - *Минимално*: 2 GB за стрийминг обработка на файлове.
  - *Препоръчително*: 8 GB+ за работа с интерактивния Streamlit UI и големи сесии в RAM.
- **Дисково пространство**: Свободно пространство поне двойно спрямо размера на обработваните TMX файлове (за временни диск-базирани SQLite бази и генерирани изходи).

---

## 🛠️ Стъпка 1: Създаване на виртуална среда

Препоръчително е винаги да използвате виртуална среда (virtual environment), за да избегнете конфликти с глобалните библиотеки.

### На Linux / macOS:
```bash
# Клонирайте или изтеглете репозиторията
cd TMX_project

# Създайте виртуална среда
python3 -m venv .venv

# Активирайте виртуалната среда
source .venv/bin/activate
```

### На Windows (Command Prompt / PowerShell):
```cmd
:: Command Prompt
python -m venv .venv
.venv\Scripts\activate

:: PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## 📦 Стъпка 2: Инсталация на пакета

Платформата предлага четири варианта за инсталация в зависимост от вашите нужди:

### Вариант A: Пълна инсталация (Препоръчително за всички функционалности)
Включва Streamlit UI, Parquet експорт, Tiktoken токенизатор и тестови инструменти:
```bash
pip install -e ".[all]"
```

### Вариант B: Базова инсталация (За сървъри и автоматизирани скриптове)
Включва ядрото, CLI и FastAPI уеб интерфейса (без Streamlit UI):
```bash
pip install -e .
```

### Вариант C: Със Streamlit UI
За data science среди с интерактивни dashboards:
```bash
pip install -e ".[streamlit]"
```

### Вариант D: За разработка и тестове (Dev mode)
```bash
pip install -e ".[dev]"
```

## ✅ Стъпка 3: Проверка на инсталацията

След приключване на инсталацията може да проверите дали всичко работи:

```bash
# 1. Изпълнение на тестовия пакет
pytest

# 2. Проверка на CLI командата
tmx-proc --help

# 3. Стартиране на уеб сървъра
tmx-web --port 8000
```

Ако всички тестове преминат и помощната информация се зареди, инсталацията е успешна!
